Mzizi
Phase 0 · research prototype

Built to make Rust better, the way TypeScript makes JavaScript better.

A general-purpose programming language with a harness at its core: the layer an agent reads.

examples/fib.mz
fn fib(n: int): int
  when n < 2
    return n
  end
  return fib(n - 1) + fib(n - 2)
end fn fib
$ mz run examples/fib.mz
fib(9) is 34
